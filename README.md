## Descripción

Este repositorio recopila análisis, ejemplos y pruebas conceptuales (PoC) sobre vectores de ataque comunes en entornos cloud. El objetivo es documentar técnicas, mitigaciones y buenas prácticas para ayudar a administradores y equipos de seguridad a entender y proteger su infraestructura.

Advertencia: el contenido es de naturaleza técnica y puede incluir demostraciones que podrían facilitar el abuso si se usan sin autorización. Está destinado exclusivamente a fines educativos y defensivos.

- Navegador para ver archivos HTML
- Herramientas opcionales: curl, jq, herramientas de análisis de seguridad (según los ejemplos incluidos)

## Cómo usar

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Lucas18062025/cloud-attack-vector-research.git
   cd cloud-attack-vector-research
   ```

2. Revisa la carpeta `docs/` para la documentación principal.
3. Lee las advertencias en los PoC antes de ejecutar cualquier script o ejemplo. Ejecuta pruebas sólo en entornos controlados y autorizados.
