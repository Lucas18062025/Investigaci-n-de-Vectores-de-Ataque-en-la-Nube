# Investigación de Vectores de Ataque y Ejecución de Ataques en Tecnologías de la Nube

Investigación técnica sobre vectores de ataque comunes en infraestructura cloud,
desarrollada como parte de mi formación en ciberseguridad ofensiva/defensiva.

## Referencia principal
NIST Special Publication 500-292 — *NIST Cloud Computing Reference Architecture*

## Contenido
- Agotamiento de recursos y DoS
- Ataques contra activos en la nube (mala configuración)
- Escalamiento de privilegios
- Recolección de credenciales
- Diagramas de seguridad en la nube

## ⚠️ Disclaimer
Todo el contenido es de carácter educativo/investigativo. No incluye pruebas
de concepto ejecutables contra sistemas de terceros ni credenciales reales.
